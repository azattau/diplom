# Птицы · карта наблюдений

Учебная система: сообщение оператора → локальная Ollama → населённый пункт → координаты из справочника → маркер на карте.

**Сайт:** https://azattau.github.io/diplom/  
**Репозиторий:** https://github.com/azattau/diplom

## Запуск на Windows

1. Установите **Python 3.10 или новее** с [python.org](https://www.python.org/downloads/). При установке включите `Add python.exe to PATH`.
2. Запустите установленную **Ollama**. В PowerShell проверьте список моделей:

   ```powershell
   ollama list
   ```

   Если моделей нет, можно скачать небольшую русскоязычную модель:

   ```powershell
   ollama pull qwen2.5:3b
   ```

   Это пример совместимой модели, а не обязательная зависимость. В интерфейсе можно выбрать другую установленную локальную модель, умеющую возвращать JSON по схеме. Качество и скорость зависят от модели и компьютера.

3. Полностью распакуйте архив проекта. Не запускайте `start.bat` прямо внутри ZIP.
4. Дважды щёлкните **`start.bat`**. Откроется окно сервера и локальный сайт. Не закрывайте окно сервера во время работы.
5. Выберите модель в поле **«Модель Ollama»**. Нажмите **«Вставить пример»**, затем **«Нанести на карту»**.
6. Нажмите на маркер. В карточке будут исходный текст и время получения сообщения. Время показано для Башкортостана, UTC+5.

Устанавливать пакеты через `pip` не нужно: сервер использует стандартную библиотеку Python. Сервер слушает только `127.0.0.1`.

Если Python Launcher выбирает старую версию Python, откройте папку в PowerShell и выполните `py -3.12 run.py` (подставьте установленную версию).

## Как пользоваться сайтом на GitHub Pages

GitHub Pages размещает только HTML, CSS и JavaScript; он **не запускает Python или Ollama**.

1. Оставьте Ollama и `start.bat` запущенными на этом же компьютере.
2. Откройте https://azattau.github.io/diplom/ и нажмите **«Подключить Ollama»**.
3. Укажите адрес `http://127.0.0.1:8765` и код подключения из окна запуска.
4. Если браузер спросит доступ к локальной сети, разрешите его для этого сайта.
5. Выберите модель и введите сообщение.

Правила доступа HTTPS-сайта к локальному HTTP-серверу зависят от браузера и его настроек. Если подключение блокируется, используйте локальный сайт из окна запуска: там работает тот же интерфейс без межсайтового подключения. Не отключайте защиту браузера и не открывайте Ollama в интернет.

При перезапуске сервера код меняется. Скопируйте новый код. Он хранится только в текущей вкладке; сообщения хранятся отдельно в локальной базе. Python не требует настройки `OLLAMA_ORIGINS`: браузер обращается к Python, а Python — к Ollama.

## Демонстрационные сообщения

Это искусственные примеры, не реальные обращения. Их нет в начальной базе.

| Текст | Ожидаемый результат при корректном извлечении моделью |
|---|---|
| В Уфе возле парка заметили птицу в 14:20. | Маркер Уфы, исходный текст, время получения; «14:20» отдельно как время из текста |
| В Стерлитамаке наблюдали птицу. | Маркер Стерлитамака |
| В селе Верхнем Абдряшево Абзелиловского района видели птицу. | Модель нормализует название; поиск составного названия с учётом района |
| В Михайловке видели птицу. | Несколько вариантов; оператор выбирает нужный район в ленте |
| Птица летела в сторону Уфы. | Нет места наблюдения; маркер не должен появиться |
| В Уфе птиц не видели. | Отрицание; маркер не должен появиться |
| Видел птицу рядом с домом. | Названия населённого пункта нет; сообщение сохраняется без точки |

LLM может ошибаться даже с JSON-схемой. Для проверки откройте **«Результат анализа»** в ленте: там показаны название, район и цитата. Ошибочное извлечение исправляется уточнением и повторной отправкой текста; редактор и удаление сообщений в первой версии не предусмотрены.

## Что реализовано

- Карта OpenStreetMap на Leaflet; адаптивный интерфейс на русском языке.
- Ручной ввод сообщений длиной до 4000 символов.
- Выбор реально установленных локальных моделей через `/api/tags`.
- Извлечение до пяти мест наблюдения одним запросом `/api/chat` с JSON Schema.
- Проверка структуры ответа и наличия дословных цитат в исходном тексте.
- Приведение к именительному падежу выполняет LLM. Python нормализует регистр, `ё/е`, тип населённого пункта и пробелы, затем ищет **точное** совпадение.
- Район учитывается, если он извлечён. Одноимённые пункты требуют явного выбора оператора. Неизвестное название не подменяется ближайшим похожим.
- Координаты только из приложенного справочника из 4561 записи, а не от LLM.
- Сообщения сохраняются в SQLite. Лента показывает последние 1000 сообщений и обновляется каждые 5 секунд, пока вкладка открыта. Более старые записи остаются в базе.
- Несколько сообщений в одной точке доступны в общей карточке маркера.
- Поиск по ленте. Поиск фильтрует ленту; карта продолжает показывать все загруженные наблюдения.
- Контроль размера запросов, токен подключения, ограниченные Origin и Host, безопасный вывод текста через `textContent`.

## Где находятся данные

`runtime/observations.sqlite3` создаётся при первом запуске. База не отправляется в GitHub и исключена из Git. Чтобы сделать резервную копию, остановите сервер и скопируйте файл базы.

`data/settlements.csv.gz` — исходный `OSM/settlments.csv` из предоставленного архива, сжатый без изменения содержимого. Районы и координаты берутся из него. Реальных сообщений из исходной работы в проекте нет. Происхождение и условия дальнейшего распространения исходного справочника в архиве не указаны.

Обработка текстов локальная. Для карты нужен интернет: браузер загружает Leaflet с unpkg.com и тайлы OpenStreetMap. Сервисы карты видят обычные сетевые запросы и область карты, но приложение не передаёт им текст сообщений.

## Структура проекта

| Путь | Назначение |
|---|---|
| `run.py` | Запуск сервера, случайный код подключения, открытие браузера |
| `backend/core.py` | Запросы к Ollama, JSON-схема и промпт, валидация, справочник, SQLite |
| `backend/server.py` | Локальный HTTP API и раздача интерфейса |
| `web/` | Интерфейс оператора, публикуемый на GitHub Pages |
| `data/settlements.csv.gz` | Справочник населённых пунктов |
| `tests/test_system.py` | Автоматические интеграционные проверки |
| `.github/workflows/pages.yml` | Проверки и публикация интерфейса |

## Проверка и другие варианты запуска

```powershell
py -3 -m unittest discover -s tests -v
py -3 run.py --no-browser
py -3 run.py --port 8766 --timeout 300
```

На macOS/Linux: `sh start.sh` или `python3 run.py`.

По умолчанию сервер ожидает Ollama на `http://127.0.0.1:11434`. Для другого локального порта: `python run.py --ollama-url http://127.0.0.1:11435`. Внешние адреса Ollama не принимаются.

При увеличении `--timeout` свыше 180 секунд интерфейс всё равно прекращает ожидание примерно через 200 секунд. Сервер может завершить обработку позднее: проверьте ленту перед повторной отправкой.

Автоматические тесты используют **имитацию HTTP-ответов Ollama**. Они проверяют программную цепочку, а не качество языковой модели. Реальный инференс на компьютере пользователя и совместимость конкретного браузера с локальной сетью требуют проверки при запуске. Для оценки качества диплома нужен отдельный размеченный набор сообщений.

## Публикация из репозитория

В Settings → Pages → Build and deployment выберите **GitHub Actions**. Workflow `Test and publish operator map` запускает проверки и публикует **только папку `web`** после изменений в `main`. Веса модели, база сообщений и Python на Pages не загружаются как работающие сервисы.

При переносе в другой GitHub-аккаунт укажите новый origin: `python run.py --pages-origin https://USERNAME.github.io`.

## Границы первой версии

Нет подключения к 112/МЧС, распознавания звонков, определения координат телефона, направления/прогноза полёта и распознавания звука или видео. Точка обозначает населённый пункт из справочника; фраза «возле парка» не геокодируется до парка. Учебный локальный сервер рассчитан на демонстрацию одним оператором, а не на промышленное развёртывание.
