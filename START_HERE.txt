ПТИЦЫ — КАРТА НАБЛЮДЕНИЙ

1. Полностью распакуйте архив.
2. Установите Python 3.10+ (python.org), если его ещё нет.
3. Запустите Ollama. Проверьте в PowerShell: ollama list
   Если моделей нет: ollama pull qwen2.5:3b
4. Дважды щёлкните start.bat. Не закрывайте окно сервера.
5. В открывшемся браузере выберите модель, введите сообщение,
   нажмите «Нанести на карту».

Сайт на GitHub: https://azattau.github.io/diplom/
Для него тоже нужны запущенные start.bat и Ollama на этом компьютере.
Нажмите «Подключить Ollama», скопируйте код из окна запуска.
Если браузер блокирует доступ — используйте локальную версию из окна запуска.

Первый запрос может быть долгим из-за загрузки модели.
Если названию соответствуют несколько мест, выберите нужное в ленте.
Нажмите маркер, чтобы увидеть время получения и полный текст сообщения.

Сообщения сохраняются в runtime/observations.sqlite3.
Распознавание зависит от выбранной модели. Координаты — из справочника.
Полная инструкция, примеры и описание архитектуры: README.md.
